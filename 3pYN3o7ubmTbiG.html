我换了 Pixel 10 Pro……

其实年初就换了，因为 Pixel 5 电池在一次吃饭中「嗷」地一下鼓包了。

但用了半年才算安稳，总结一下更换的东西。

5G 与 VoLTE

首先要解决的肯定是通信问题，依然是 Sun Dream 大佬做了个模块，通吃 Pixel 5 到 Pixel 10。

地址：https://pan.baidu.com/s/15B_MtwnnGWRsrjEAbG1Srw?pwd=fx20

直接刷入就完事了，我也算是用上 5G 的人了（虽然还是 4G 套餐）。

换机备份与恢复

Swift Backup 实在是太好用了，这次从 Pixel 5 换到 Pixel 10 Pro 可比上次 Pixel 3 换到 Pixel 5 轻松太多了。

不过需要注意的是一些区分设备的 APP 最好不要迁移数据，重新设置会好一些，比如 Syncthing-Fork。

返回键右置

最开始我继续延续 Pixel 5 上的使用思路，使用 PixelXpert 来交换返回键与多任务键的位置。

但前一段时间，PX Team 因种种原因关闭了该项目。

于是我重新开始互联网上检索相关信息，这时才发现，我这台 Android 16 的 Pixel 10 Pro，已经内置了三大金刚按钮布局自定义。

自定义按钮顺序

在此向 PixelXpert 项目及 PX Team 致以诚挚的感谢。

LSPosed

随着 LSPosed 更新到 API 102 后，部分模块也受到了影响，好在目前解决了。

MiPush

详细内容更新在 原文 处。

剪贴板白名单

API 101 版本地址：https://github.com/hxreborn/io.github.tehcneko.clipboardwhitelist

Hachidori

使用群组中发布的 0.35 内测版。

骚扰电话、短信

之前一直用 CC 来电拦截，后来发现了一款叫 拦截猫 的 APP，用了一段时间还不错，直到今天我发现了另一款更适合 Pixel 体质的软件。

它就是 Pixel Telo。

不仅如此，开发者还有多款为 Pixel 量身打造的应用，短信应用 Pixel Text 就是如此。

另外还有可以实现工作日闹钟的应用，我因为之前自己已经实现，就没有下载使用了。

有兴趣的可以前往 https://pixel.mystery0.app/ 自行查看作者开发的程序。

零散内容

  • 使用了 Obtainium 来维护一些软件的更新

  • 将阅读从原版更换为了 MD3 版本（https://github.com/HapeLee/legado-with-MD3）

  • Breezy Weather 的 Pixel 天气图标我很喜欢，但不喜欢那紫色的月亮，于是改成了蓝色（https://github.com/huaxianyan/pixel-icon-provider）

写在最后

用了小半年的 Pixel 10 Pro，还是比较满意的，除了太滑让我不得不上了手机壳外，别的都挺不错。
